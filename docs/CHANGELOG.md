# 更新日志

## v1.2.0（versionCode 5）— 2026-09-17

### 本地化存储（图片不占服务器）
- 照片图片文件只存设备本地：APK 存应用外部专属目录 `album/`（原图 + 256px 缩略图），H5 存 IndexedDB
- 服务器不再保存任何图片文件：远程数据库仅登记元数据（本地路径、备注、拍摄时间、设备、坐标）
- 拍摄照片同时保存到系统相册（saveToGallery）；相册选图申请相册读取权限（Android 13+ READ_MEDIA_IMAGES）
- 离线可用：先存本地再联网登记；登记失败自动进入待同步队列，联网后补登（图片始终不丢）
- 旧版本历史照片（远程图片）继续通过服务器 /uploads 展示，不受影响
- `POST /api/photos` 由 multipart 上传改为 JSON 元数据登记（老版本 APK 的上传将失败，请升级到 v1.2.0）

### 海报修复
- 修复「胶片墙」海报报错（drawWallPoster 缺少 variant 参数导致引用错误）
- 修复「换一版」在胶片墙下无响应（同一根因）
- 海报缩略图改为本地优先加载，兼容 blob / capacitor 本地地址

## v1.1.1（versionCode 3）— 2026-09-17

### 登录修复与重设计
- 移除「测试阶段免密」通道：全账号（App 与网页）统一必须密码登录
- 登录页全新设计：渐变背景 + 浮动光斑、图标输入框（焦点高亮）、密码可见切换、按钮 spinner 加载动画、错误提示条
- 客户端前置校验：账号格式、密码长度（≥6 位），服务端错误码 1005/1006/1007 透出
- 历史无密码老账号：首次登录所填密码即初始密码（自动补设）
- 同一账号在 App 与网页通用（ssoUserId 统一 app- 前缀）

## v1.1.0（versionCode 2）— 2026-09-17

P0 / P1 功能补全（除「release 签名」外全部落地）。

### 上传可靠性（P0）
- EXIF 解析（压缩前）：拍摄时间、设备（Make+Model）、GPS 自动定位
- 客户端压缩：最长边 2048 / JPEG q0.85（GIF 跳过）
- 断网/失败自动入持久化队列（IndexedDB `map_album_db.pending_uploads`）
- 联网自动补传（网络事件 + 2s 延迟防抖），横幅显示待传数量、一键重试

### 原生相册多选（P0）
- `Camera.pickImages(limit 20)`，webPath→blob→File，单选旧设备回退

### 密码登录（P0）
- `app-` 渠道必须密码：首次登录设置，之后校验（SHA-256 摘要）
- 错误码 1005/1006/1007；`dev-` 渠道（Web 调试）免密
- 新增 `PUT /user/profile` 昵称更新

### HTTPS（P0）
- 自签证书 SAN `IP:59.110.53.169`（10 年），nginx 443 就绪
- 客户端 API 基址运行时探测：HTTPS 可达则缓存 24h，失败自动回退 HTTP
- Android `network_security_config`：信任自签证书 + 服务器域明文回退白名单

### 相册时间轴（P1）
- 新增相册视图：按拍摄月份分组 + 三列宫格，点击进光箱

### 搜索我的内容（P1）

### 应用内更新（P1）
- `GET /api/app/version` + 更新弹窗 + APK 直链（`/apk/`）
