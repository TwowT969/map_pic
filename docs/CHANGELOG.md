# 更新日志

## v1.3.7（versionCode 13）— 2026-09-18

### 相册体验优化
- **秒开**：原生生成 256px 磁盘缩略图（cacheDir 永久缓存，系统缩略图通道优先），网格不再解码原图——上一版加载慢的主因；权限请求改为与首屏查询并行，不阻塞渲染
- **取消数量上限**：多选不再限 20 张，想选多少选多少
- **界面更干净**：移除顶部提示行与底部状态条，只留网格与"确定(n)"

## v1.3.6（versionCode 12）— 2026-09-18

### 相册选择重做（微信式）
- 新增原生 Gallery 插件直读系统相册（MediaStore，按时间倒序），不再拉起系统文件管理器（DocumentsUI）
- 全新应用内选图页：微信式三列网格 + 按选择顺序编号的多选角标 + 顶栏"确定(n)"，一次最多 20 张
- 滚动分页加载（每页 72 张，首屏查询一次会话内缓存，翻页零延迟），点击"相册"标签即秒开
- 点位面板"从相册选择"同步切换到应用内相册；网页端保持浏览器文件选择
- 相册选择器支持返回键/Escape 逐层关闭

## v1.3.4（versionCode 10）— 2026-09-18

### 实测反馈修复
- 点击聚合点位（成员几乎重合、无法展开时）改为合并展示簇内全部点位的图片列表，不再只显示最近更新一个点位的单张图片

## v1.2.0（versionCode 5）— 2026-09-17

### 本地化存储（图片不占服务器）
- 照片图片文件只存设备本地：APK 存应用外部专属目录 `album/`（原图 + 256px 缩略图），H5 存 IndexedDB
- 服务器不再保存任何图片文件：远程数据库仅登记元数据（本地路径、备注、拍摄时间、设备、坐标）
- 拍摄照片同时保存到系统相册（saveToGallery）；相册选图申请相册读取权限（Android 13+ READ_MEDIA_IMAGES）
- 离线可用：先存本地再联网登记；登记失败自动进入待同步队列，联网后补登（图片始终不丢）
- 旧版本历史照片（远程图片）继续通过服务器 /uploads 展示，不受影响
- `POST /api/photos` 由 multipart 上传改为 JSON 元数据登记（老版本 APK 的上传将失败，请升级到 v1.2.0）

### 海报修复
- 修复「胶片墙」海报报错（drawWallPoster 缺少 variant 参数导致引用错误）
- 修复「换一版」在胶片墙下无响应（同一根因）
- 海报缩略图改为本地优先加载，兼容 blob / capacitor 本地地址
